# Smart Project Manager

A full-stack project and task management application built to demonstrate Python backend development, frontend development, database integration, automated testing, and deployment.

## Tech Stack

* **Backend:** Python, FastAPI
* **Frontend:** Vue 3, JavaScript
* **Database:** PostgreSQL
* **ORM:** SQLAlchemy
* **Testing:** Pytest
* **Version Control:** Git and GitHub
* **Containerization:** Docker and Docker Compose
* **CI/CD:** GitHub Actions
* **Orchestration:** Kubernetes

## Planned Features

* Create, view, update, and delete projects.
* Create and manage tasks within projects.
* Track task status and priorities.
* Store project and task information in a database.
* Validate API requests and handle errors.
* Write automated tests for backend APIs.
* Build a responsive frontend.
* Run the application using Docker.
* Automate tests using GitHub Actions.
